# Password Strength Checker 🔐

A simple Python script to check the strength of a password based on common security criteria.  
This is useful in **DevOps** and general security practices to ensure strong password policies.

---

## Features
- ✅ Minimum length: 8 characters
- ✅ Contains both uppercase and lowercase letters
- ✅ Contains at least one digit (0-9)
- ✅ Contains at least one special character (!, @, #, $, %)
- ✅ Rates password strength as **Weak**, **Medium**, or **Strong**

---

## Usage

1. Clone or download this repository.
2. Run the script using Python:

```bash
python password_checker.py
